# Чек-лист проверки формы регистрации

**Проект:** Регистрация нового пользователя

**Тип тестирования:** Ручное тестирование (Manual Testing)

**Автор:** Ulugbek Zinatov

## 1. Позитивное тестирование (Positive Testing)

- [ ] Регистрация с корректным именем
- [ ] Регистрация с корректной фамилией
- [ ] Регистрация с корректным адресом электронной почты
- [ ] Регистрация с корректным номером телефона
- [ ] Регистрация с корректным паролем
- [ ] Регистрация с совпадающими паролями
- [ ] Успешная регистрация со всеми корректными данными
- [ ] Отображение сообщения об успешной регистрации

## 2. Негативное тестирование (Negative Testing)

- [ ] Регистрация с пустым полем имени
- [ ] Регистрация с пустым полем фамилии
- [ ] Регистрация с пустым полем электронной почты
- [ ] Регистрация с некорректным форматом электронной почты
- [ ] Регистрация с некорректным номером телефона
- [ ] Регистрация с пустым полем пароля
- [ ] Регистрация с коротким паролем
- [ ] Регистрация с несовпадающими паролями
- [ ] Регистрация с уже зарегистрированной электронной почтой
- [ ] Отправка формы со всеми пустыми полями

## 3. Тестирование интерфейса (UI Testing)

- [ ] Все поля регистрации отображаются
- [ ] Названия полей отображаются корректно
- [ ] Кнопка регистрации видна пользователю
- [ ] Сообщения об ошибках отображаются корректно
- [ ] Пароль скрыт по умолчанию
- [ ] Форма регистрации отображается корректно

## 4. Тестирование безопасности (Security Testing)

- [ ] Пароль не отображается в открытом виде
- [ ] Пароль не отображается в URL
- [ ] Подтверждение пароля проверяется системой
